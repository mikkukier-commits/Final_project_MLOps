# 05. Бізнес-обґрунтування та розрахунок TCO (Business Justification & Financial Model)

## 1. Виконавче резюме

Ми запитуємо затвердження інвестиції у MLOps-платформу **SupportFlow AI**: операційний бюджет (OPEX) у розмірі **$1,440,000 за 1-й рік ($120,000/міс)** та початкові капітальні витрати (CAPEX) **$350,000** на впровадження, що дає сукупний 3-річний TCO **$5,000,000**. Проєкт вирішує критичну проблему неконтрольованої вартості комерційних LLM API (**$2,304,000/рік** при поточних 8M тикетів/міс) та усуває ризики фінансових галюцинацій і регуляторних штрафів (**EU AI Act** до €35M, **GDPR**), які зараз блокують вихід нашого продукту в high-stakes процеси білінгу й chargebacks. Гібридна архітектура (self-hosted Llama 3.3 70B + класичний ML + ізольований Pinecone RAG на AWS EKS) забезпечує **$864,000 прямої річної економії** вже в 1-му році, знижує цільову юніт-вартість обробки звернення на **50%** (з **$0.024** до **$0.012** на масштабі 10M+ тикетів/міс, при поточному старті **$0.015** на 8M/міс), досягає **148% 3-річного ROI** ($7.40M чистої вигоди) та окупає капітальні інвестиції за **7.4 місяці**. Для запуску в межах Q2 необхідно затвердити бюджет до **15 березня 2027 року**.

---

## 2. Бізнес-проблема

SupportFlow AI досяг product-market fit на стадії Series B: платформою користуються **1,200 enterprise-клієнтів** у ЄС і США із середнім ARR $18,000 (**$21.6M ARR**), генеруючи **8,000,000 клієнтських звернень щомісяця** (96M/рік) на 12 мовах. Однак подальше зростання та маржинальність бізнесу впираються у три системні бар'єри:

1. **Економічна неефективність 100% комерційних API:** Поточна залежність від зовнішніх LLM API обходиться у **$0.024 за тикет** (**$192,000/міс** або **$2,304,000/рік**). При плановому зростанні обсягу до 10M тикетів/міс у 2-му році та 12M/міс у 3-му році витрати лише на API зросли б до **$2.88M** і **$3.46M/рік**, що з'їдає валову маржу B2B SaaS.
2. **Некеровані інциденти галюцинацій (Фінансовий тригер):** Три місяці тому у ключового клієнта (~15% ARR) мовна модель сформувала неіснуюче підтвердження безкоштовного повернення дорогого товару. SupportFlow AI зазнала **$23,000 прямих збитків** та репутаційного удару. Без формального MLOps governance Рада директорів заблокувала запуск нових high-stakes функцій (автоматизація білінгу та оскарження платежів — chargebacks), що стримує апсел існуючої бази.
3. **Регуляторні ризики в ЄС та США:** Робота з клієнтськими даними в ЄС підпадає під вимоги **GDPR** (штрафи до 4% обороту, обов'язок 72-годинного повідомлення про інциденти) та **EU AI Act** (санкції до €35M або 7% глобального обороту за відсутність технічної документації, аудиторського логування за 12 місяців та людського нагляду). Поточні розрізнені скрипти не проходять enterprise-аудит безпеки великих клієнтів.

## 3. Огляд пропонованого рішення

Ми впроваджуємо єдину керовану платформу **AI PM MLOps Governance** на базі **AWS** (детальне обґрунтування вибору технологій зафіксовано в `01_ADR.md`):

- **Гібридний інференс (ADR-001):** 95% запитів обробляє власна fine-tuned модель **Llama 3.3 70B** на GPU-кластері AWS EKS (`g5.2xlarge`) разом із легким класифікатором намірів на CPU (`m6i.xlarge`); <5% надскладних або пікових запитів маршрутизуються на резервний комерційний API після знеособлення PII.
- **Контрольована доставка та якість (ADR-002, ADR-003):** Усі релізи проходять автоматизований пайплайн тренування (GitLab CI + AWS Step Functions) із реєстрацією в **MLflow Registry**, обов'язковим 36-пунктним реліз-чеклістом та **Canary-розгортанням через Argo Rollouts** (5% → 25% → 100%) з автоматичним 30-секундним відкотом.
- **Безпека, ізоляція та аудит (ADR-004, ADR-005):** Захист **NeMo Guardrails** проти prompt injection, ізоляція ~3.5M векторів клієнтських баз знань у **Pinecone Enterprise** (`namespace = tenant_id`), моніторинг у **Prometheus/Grafana/Loki** та незмінний аудит у **AWS S3 Object Lock**.

## 5. Юніт-економіка та аналіз чутливості

### Декомпозиція вартості одного прогнозу (при поточних 8M звернень/міс, Y1 OPEX $120,000/міс)

- **Cost per classical ML prediction (Intent / Priority / Sentiment):** **$0.0004** (8M класифікацій/міс на CPU-нодах `m6i.xlarge` та експортері Prometheus — ~$3,200/міс).
- **Cost per LLM + RAG direct inference (без урахування фіксованого штату MLOps):** **$0.0102** (95% Llama 3.3 70B на GPU + Pinecone + Network + <5% Fallback API = ~$81,800/міс на 8M тикетів).
- **Blended cost per ticket:**
  - Пряма інфраструктурна собівартість (без фіксованого персоналу, 8M/міс): **$0.0106 / тикет**.
  - Повна операційна собівартість (Fully-loaded OPEX $120K/міс на старті 8M/міс): **$0.0150 / тикет** (проти **$0.0240** при 100% комерційному API — зниження на 37.5% з першого дня).
  - Цільова повна юніт-вартість на масштабі 10M–12M тикетів/міс (Year 1 exit / Year 2, за рахунок розподілу фіксованого персоналу й базового кластера): **$0.0120 / тикет** (зниження на **50%** відносно $0.0240).

### Точка беззбитковості

Постійні місячні витрати платформи (персонал $35K + Pinecone і сховище $15K + інструменти безпеки/моніторингу $10K + базовий зарезервований EKS/Network кластер $24.8K) становлять **$84,800/міс**. Змінні витрати на автоскейлінг GPU, мережевий трафік і 5% API fallback становлять **$0.0044/тикет** (разом при 8M/міс: `$84,800 + 8M × $0.0044 = $120,000/міс`).

- **Формула Break-even проти комерційного API ($0.024/тикет):**
  $$N_{\text{break-even}} = \frac{\$84,800}{\$0.0240 - \$0.0044} = \frac{\$84,800}{\$0.0196} \approx \mathbf{4,326,531 \text{ тикетів/міс}}$$
- Поточний обсяг **8.0M тикетів/міс** перевищує точку беззбитковості на **85%**, створюючи надійний запас міцності.

## 7. Розрахунок ROI та періоду окупності

Оцінка проведена за 3-річним горизонтом відносно базового сценарію збереження 100% комерційних API (Do Nothing):

### Пряма фінансова віддача

- **Уникнені витрати на комерційні LLM API ($0.024/тикет):**
  - Year 1 (96M тикетів): `$2,304,000`
  - Year 2 (120M тикетів): `$2,880,000`
  - Year 3 (144M тикетів): `$3,456,000`
  - _Разом уникнені витрати API:_ **$8,640,000** (що після вирахування Year 1 OPEX $1,440,000 дає **$864,000 прямої чистої економії у 1-й рік**).
- **Уникнені інциденти галюцинацій та простої (Avoided Incidents & Downtime):** На основі реального інциденту $23K + ризику розірвання enterprise-контрактів (~$200K/рік імовірних втрат при відсутності Guardrails/Canary) = **$200,000/рік × 3 = $600,000**.
- **Готовність до комплаєнсу:** Повне усунення ризику санкцій EU AI Act (до €35M) та GDPR (до 4% обороту — ~$864K/рік) як обов'язкова умова утримання клієнтів ЄС (не капіталізується в ROI, але слугує критичним захисним фактором).

### Непряма бізнес-віддача

- **Економія на масштабуванні департаменту підтримки клієнтів:** Підвищення стабільності та довіри до авто-вирішення (60%→72% без операторів) дозволяє обслуговувати зростання до 12M тикетів без найму ~10 додаткових L1-агентів = **$500,000/рік × 3 = $1,500,000**.
- **Утримання ARR та розблокування enterprise-сегменту (Retention & Upsell):** Зниження відтоку на 5% (збереження **$1,080,000 ARR/рік** при базі $21.6M ARR) плюс запуск тарифного модуля _Billing & Chargebacks_ дає консервативний чистий маржинальний внесок **~$553,333/рік × 3 = $1,660,000**.

### Підсумкові інвестиційні показники

- **Сукупна валова вигода за 3 роки (Gross 3Y Value):** `$8,640,000 + $600,000 + $1,500,000 + $1,660,000` = **$12,400,000**.
- **Сукупний 3-річний TCO (Total 3Y Investment):** **$5,000,000**.
- **Чиста вигода за 3 роки (3Y Net Benefit):** `$12,400,000 - $5,000,000` = **$7,400,000**.
- **3-річний ROI:**
  $$\text{ROI} = \frac{\$7,400,000}{\$5,000,000} \times 100\% = \mathbf{148\%}$$
- **Період окупності капітальних витрат (Payback Period):** З урахуванням 2.5 місяців фази налаштування до промислового запуску та початкового CAPEX **$350,000**, який покривається щомісячною прямою економією на API (**$72,000/міс** = `$864,000 / 12` у 1-му році):
  $$\text{Payback} = 2.5 + \frac{\$350,000}{\$72,000/\text{міс}} = 2.5 + 4.86 = \mathbf{7.36 \approx 7.4 \text{ місяці}}$$

## 8. Ризики інвестиції та заходи мінімізації

1. **Ризик перевитрат на GPU та дефіциту `g5.2xlarge` у регіоні ЄС:** Під час пікового трафіку автоскейлінг або перемикання на комерційний API може перевищити місячний бюджет $120K. _Мінімізація:_ Резервування 4 базових GPU-нод за AWS 1-year Savings Plan (~32% знижки), суворі ліміти HPA (max 8 GPU-нод), автоматичний circuit breaker на бюджет fallback API ($10K/міс) та алерти AWS Budgets при 80% місячного ліміту.
2. **Ризик зниження обсягу звернень нижче точки беззбитковості (4.33M/міс):** Якщо через втрату великих клієнтів обсяг впаде до 0.5× (4M/міс), власний кластер коштуватиме $0.0256/тикет (дорожче за API). _Мінімізація:_ Гнучка архітектура адаптерів дозволяє не продовжувати 1-річний Savings Plan у разі падіння трафіку та миттєво перемкнути основний потік назад на API при щоквартальному перегляді ADR-001.
3. **Ризик затримки найму або втрати MLOps-інженерів:** Складність підтримки EKS + vLLM + MLflow залежить від 2 MLOps FTE; затримка найму чи звільнення загрожує простоєм. _Мінімізація:_ Повна автоматизація інфраструктури як коду (Terraform) та GitOps-деплоїв (Argo CD), залучення крос-навчання 1 бекенд-інженера як резервного on-call (ДЗ 3/5) та документування всіх інцидентів у `04_Incident_Runbook.md`.

## 9. Дорожня карта та ключові етапи на 12 місяців

- **Місяці 1–2 (Березень – Квітень 2027) — Фундамент і запуск Production Canary:**
  - _15 березня 2027:_ Затвердження бюджету Радою директорів і CPO.
