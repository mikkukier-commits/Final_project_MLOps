# 00. Інтеграційна записка: Еволюція ДЗ 1–5 у пакет MLOps Governance для SupportFlow AI

## 1. Продуктова легенда та бізнес-контекст

**SupportFlow AI** — B2B SaaS-платформа автоматизації підтримки клієнтів для e-commerce брендів у ЄС та США (Series B, 1,200 корпоративних клієнтів, середній ARR $18K, сукупний ARR **$21.6M**), що обробляє **8M звернень щомісяця** (96M/рік) на 12 мовах (60% авто-відповідей, 40% чернеток операторам). Гібридний стек на **AWS** поєднує **LLM** (fine-tuned Llama 3.3 70B із fallback на комерційний API <5%), **класичну ML-модель** (класифікатор намірів на 25 категорій, пріоритизація P1/P2/P3, тональність) і **RAG** (Pinecone Enterprise, ~3.5M векторів у клієнтських просторах імен). Команда налічує 5 ML-інженерів, 2 MLOps-інженерів, 3 бекенд-інженерів та Senior AI PM (звітує CPO). Тригером став інцидент 3 місяці тому у ключового клієнта (~15% ARR): помилкове підтвердження безкоштовного повернення товару коштувало **$23,000 прямих збитків**, після чого Рада директорів вимагає повний governance-план до **15 березня 2027 року** перед виходом у білінг і chargebacks.

## 2. Інтеграція та адаптація напрацювань ДЗ 1–5

- **ДЗ 1 (Контейнеризація):** Перенесено підхід multi-stage збірок на `python:3.13-slim` замість `python:3.13` (у ДЗ 1 це скоротило образ із **~3.6 GB** до **400–800 MB**, збірку з 20 до 7 хв, старт із 2 хв до 20–30 с), `.dockerignore`, фіксований `requirements.txt`, `compose.yaml` та parity-тести. _Що перероблено:_ критерії ДЗ 1 покривали лише `torchvision`-класифікатор і не пройшли staging через брак доказів безпеки; у `03_Release_Checklist.md` їх переписано під продакшн-поріг `≤ 650 MB` для CPU-сервісів, окремий GPU-образ vLLM із вагами в S3, сканування Trivy (0 Critical/High CVE) та PII/injection гейти.
- **ДЗ 2 (Kubernetes / AWS EKS):** Перенесено ізоляцію Dev/Staging/Prod, схему «окремий `prod`-кластер + спільний `dev/staging`», розділення CPU/GPU node groups, RBAC і resource quotas. _Що перероблено:_ у ДЗ 2 GPU та кластерний тренінг були опціональними; у `01_ADR.md` (ADR-001) і `05_Business_Justification.md` введено постійний пул `g5.2xlarge` із HPA-масштабуванням (`~$60.27/год` інференсу) та жорстке мережеве розділення `prod-ml`, `prod-llm`, `prod-rag`.
- **ДЗ 3 (GitOps / Argo CD):** Перенесено Git як джерело істини, контроль статусів `Synced`/`OutOfSync`/`Degraded`, обмеження `auto-sync`/`prune` у `prod` і правило, що `Synced` не гарантує якісного інференсу. _Що перероблено:_ ручний revert із ДЗ 3 замінено на **Argo Rollouts Canary (5% → 25% → 100%)** із авто-відкатом за **30 сек** (`01_ADR.md`, ADR-002), а регламент розслідування `OutOfSync`/`Degraded` переведено на мову PM у `04_Incident_Runbook.md` (Сценарій 3).
- **ДЗ 4 (MLflow + Prometheus):** Перенесено відбір кандидата `rf-depth3` (`accuracy = 0.956`, `loss = 0.141` проти `logreg-baseline` `0.933/0.191`) і експорт `mlflow_accuracy`/`mlflow_loss` у Prometheus за `run_id`. _Що перероблено:_ ДЗ 4 мало висновок _«Need more experiments»_ через 45 тестових зразків і відсутність класових метрик та drift-контролю; для SupportFlow AI це масштабовано до 25 класів на 12M рядків (`F1 ≥ 0.92`, `PSI < 0.15`), додано LLM-метрики (галюцинації `< 0.5%`, Guardrails) та S3 Object Lock аудит (ADR-003, ADR-004).
- **ДЗ 5 (Automated Training Pipeline):** Перенесено зв'язку `GitLab CI → AWS Step Functions → Data validation → Training → Evaluation → MLflow candidate → Manual approval`, правило `SUCCEEDED ≠ prod-ready` і SLA ескалації (4 год / 1 день, негайно для security). _Що перероблено:_ додано автоматичний PII-скринінг Presidio/Comprehend у `DataValidation` та red-team тести до схвалення релізу.

## 3. Нові компоненти фінального проєкту та крос-узгодженість

1. **Модель загроз гібридного ШІ (`02_Threat_Model.md`):** 16 загроз із грошовою оцінкою ризику, матрицею 3×3 та аналізом поверхні атак для LLM, ML та RAG.
2. **3-річний TCO та Unit Economics (`05_Business_Justification.md`):** Бюджет **$1,440,000/рік OPEX ($120K/міс) + $350,000 CAPEX** ($5.0M за 3 роки), точка беззбитковості **4.33M тикетів/міс**, зниження вартості з **$0.024** до **$0.015** (8M/міс) і **$0.012** (10M+/міс), пряма економія **$864,000/рік**, **148% ROI**, окупність **7.4 місяці**.
3. **Комплаєнс EU AI Act та GDPR:** Незмінне логування S3 Object Lock (12 міс), Технічний файл Статті 11 та 72-годинний протокол повідомлення про витоки PII.
4. **Операційні Runbooks (`04_Incident_Runbook.md`) та 36-пунктний Release Checklist (`03_Release_Checklist.md`):** Скрізна прив'язка всіх ризиків, ролей та чисел між текстовими файлами, `06_Stakeholder_Presentation.pdf` і `07_Executive_Summary.md`.
